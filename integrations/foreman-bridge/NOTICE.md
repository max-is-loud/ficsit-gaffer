These components were independently developed for the private Foreman derivative.
No publication licence was selected for the standalone source repositories.
Importing them here does not relicense them under the parent application's
Apache-2.0 licence. Publication/licensing remains a separate decision.

The plugin uses Satisfactory Mod Loader interfaces; applicable GPLv3 attribution
and licence obligations for SML and derived interfaces remain in place. Unreal,
Wwise and Satisfactory retain their owners' terms. Their SDKs, libraries, assets
and binaries are not included. The receiver remains a separate process with no
Foreman application code dependency. No FRM code was copied into either component.

See each component's README and the source commit/file hashes in
`source-manifest.json` for provenance. This notice records the existing boundary;
it does not grant new rights to third-party material.
